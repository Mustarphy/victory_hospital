UCSF Health sets headings in **Neulis Neue** (Adam Ladd Design), a commercial font that is not
bundled here. To use it, buy a self-hosted webfont licence from the foundry or use an Adobe
Fonts web project, then add an `@font-face` rule for `'Neulis Neue'` in `src/index.css`. The
heading font stack already lists it first.
